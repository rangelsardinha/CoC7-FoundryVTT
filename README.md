## Visão geral

*Leia este documento em outros idiomas: [English](README.md), [简体中文](README_zh-CN.md).*

Uma implementação do sistema de Chamado de Cthulhu 7ª Edição para o [Foundry Virtual Tabletop](http://foundryvtt.com). Ela inclui fichas e o sistema, além de alguns compêndios de exemplo.

Se tiver sugestões ou comentários, visite o canal `#chaosium` no Discord do Foundry ([servidor do Foundry](https://discord.gg/foundryvtt)) ou consulte as [diretrizes de contribuição](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT/blob/develop/.github/CONTRIBUTING.md).

Para ver a lista de alterações, consulte o [registro de alterações](https://github.com/Miskatonic-Investigative-Society/CoC7-FoundryVTT/blob/develop/.github/CHANGELOG.md).

### Aviso

Este projeto não inclui materiais dos livros oficiais. Para jogar, você precisará cadastrar manualmente armas, perícias, itens etc. O sistema fornece apenas algumas perícias básicas que podem ser usadas como exemplos.

## Uso

Instale no Foundry VTT pela aba **Sistemas de jogo**, usando este manifesto:
`https://github.com/rangelsardinha/CoC7-FoundryVTT/releases/latest/download/system.json`

Você também pode procurar por “Call of Cthulhu 7th edition” no catálogo de pacotes.

- O compêndio **Exemplos** inclui uma ficha de personagem de 1920, pronta para importar, além de exemplos de NPC e criatura.
- O compêndio **Perícias** contém um conjunto de perícias básicas para os personagens.
- O compêndio **Armas** contém uma arma de teste.
- O compêndio **Solicitações de rolagem** contém diversos links para diferentes tipos de rolagem.
